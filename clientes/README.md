# Perfiles de clientes

Cada carpeta es un perfil independiente de `/editar-reel` (branding y reglas). **Solo branding**: los clips y los
renders de los clientes nunca se suben al repo (ver `.gitignore`).

Para usar un perfil en una sesión: `bash clientes/usar.sh <cliente>` (copia su `config.json` a la skill y crea sus
carpetas de clips y proyectos). Claude además lee `perfil.md` y aplica `reel-defaults.json` en cada `reel.json`.
